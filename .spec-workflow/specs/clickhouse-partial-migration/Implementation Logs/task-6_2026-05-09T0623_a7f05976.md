### API Endpoints

#### GET /api/analytics/collection_count_view
- **Purpose:** Return PostgREST-compatible collection_count_view rows from the latest completed ClickHouse snapshot when fresh, or fallback to existing PostgREST on stale/error/forced/circuit-open conditions.
- **Location:** packages/api/src/collection-count/server.ts:69
- **Request Format:** No body. Query string is accepted and ignored for compatibility. Optional header X-Disable-Fallback: true forces ClickHouse-only behavior for comparison scripts.
